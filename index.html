Built in, not bolted on

Tinted, rounded cards that follow your Material You colors.

Updates built in

New builds arrive in Settings, System, Updater. No wipe, no reflashing Google apps.

INSTALL

Install in four steps

The full guide (INSTALL.md) comes with every release. Here's the short version.

Open releases

  1. Unlock and update

    Unlock the bootloader and update to the latest stock Android first.

  2. Flash the images

    In fastboot, flash boot, dtbo, vendor_kernel_boot and vendor_boot from the release.

  3. Format and sideload

    In recovery, format data, then Apply from ADB and sideload the bitDroid zip.

  4. Add Google apps

    Reboot to recovery when asked, sideload the GApps zip from the release, then reboot.

A clean install wipes your phone, so back up first. Never relock the bootloader while running a custom ROM.

OPEN SOURCE

Build it yourself

The manifest swaps the LineageOS repos we change for ours, so you can build bitDroid for your own device on top of LineageOS 24.

Source on GitHub bitDroidOS org 
# LineageOS 24 + bitDroid
repo init -u https://github.com/LineageOS/android.git \
  -b lineage-24.0 --git-lfs
git clone https://github.com/bitDroidOS/local_manifests \
  .repo/local_manifests
repo sync -c -j8
source build/envsetup.sh
breakfast <device> && m bacon
